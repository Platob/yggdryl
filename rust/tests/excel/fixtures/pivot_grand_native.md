# Native pivot grand-total order

The answer-free input manifest and workbook were generated by `.scratch/build-p6-pivot-grand-discrimination.py`. Excel 16.0 build 20430.0 (French UI) created ten native pivots in an owned workbook. Every pivot refreshed successfully; before-save, after-save and after-reopen snapshots matched, with cleanup complete. The JSON records exact input and observed IEEE-754 bits and SHA-256 provenance.

Four interleaved East(1e16,-1e16)/West(1,2) permutations yielded East 0, West 3, grand 3 despite differing raw source folds. East(1e16,1,-1e16) yielded 0 and grand 2; East(1e16,-1e16,1) yielded 1 and grand 3. These observations support ordered per-item accumulation followed by completed-item grand aggregation for this corpus. They do not prove a universal merge law or the ordering of every aggregate. Native Excel authored populated cache records; the project writer's mandated empty-record contract is a separate acceptance test.
